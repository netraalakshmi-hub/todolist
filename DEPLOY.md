# Deploy Guide (Render)

This project deploys as one Node web service:
- Backend runs Express
- Frontend is built from React and served by backend

## 1) Push code to GitHub
Push this repository to GitHub first.

## 2) Create service from Blueprint
In Render:
1. New +
2. Blueprint
3. Select your repository
4. Render reads `render.yaml` and creates the service

## 3) Set environment values
In Render service settings, set:
- `CORS_ORIGINS` = your deployed app URL (example: `https://your-app.onrender.com`)

`JWT_SECRET` is auto-generated by blueprint.

## 4) Verify
After deploy completes:
- Open: `/api/health`
- Open app root URL and test sign up, sign in, add task

## Notes
- SQLite data is stored on mounted disk at `backend/data`.
- If you change backend/frontend code, push again to trigger redeploy.
